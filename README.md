# 🦊 Fuxis Mathe-Abenteuer – 2. Klasse (Baden-Württemberg)

Eine Touch-optimierte Mathe-Lern-App für Tablet & Handy: 8 Module nach Art der Inhalte,
vor jeder Übungsrunde Beispiele, Sterne, Sound und Konfetti.

## Nutzen
- `index.html` im Browser öffnen – kein Internet nötig, keine Installation
- Fortschritt (Sterne) wird lokal auf dem Gerät gespeichert
